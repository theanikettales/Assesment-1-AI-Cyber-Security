# 🛡️ Cyber Threat Classifier

A simple **rule-based AI project** that detects common cyber threats in messages using keyword matching.

### 🚨 Detects
- 🎣 Phishing
- 🦠 Malware
- 🔐 Ransomware
- ✅ Safe Messages

### ⚙️ How It Works
The system scans each message for suspicious keywords, calculates a threat score, and predicts the most likely category.

### 📊 Results
**28/28 messages classified correctly — 100% accuracy** on the provided classroom dataset.

### 🧰 Tech Stack
`Python` • `Pandas` • `Matplotlib` • `Scikit-learn` • `Google Colab`

### 📁 Output
The project generates:
- Threat predictions
- Keyword matches
- Risk levels & recommended actions
- Category visualization
- `Lab1_Final_Result.csv`
